# 我在 / NearbyIM 0.3.3 — 更新规划 / Release plan

这是开发范围，**不是正式发布说明或验收通过声明**。进度与证据统一记录在 [Issue #55](https://github.com/GHOST-AKU/wozai/issues/55) 及其关联 Issues。

## 版本与构建

正式版仍为 **v0.3.2**。已发布的 **v0.3.3-preview.1** 仅包含 Apple / Terminal，保留其原附件与内部版本。此前 preview.2/build13、preview.3/build14 及 PR #61/#62 保持各自来源与验证范围；当前源码的 Android、Windows/Linux GUI、Apple 和 Terminal 构建版本统一递增为 **0.3.3-preview.4**，后续递增 preview.N。当前源码版本变更不表示新预览包已经发布，合入、自动检查、真机验收和发布仍分别记录。

| 位置 | 下一轮构建的版本 |
| --- | --- |
| Android versionName、应用内与诊断 | `0.3.3-preview.4` |
| Android versionCode | `15`（固定证书、包名与数据目录不变） |
| Windows/Linux GUI 应用内、诊断、下载文件名 | `0.3.3-preview.4` |
| Windows/Linux jpackage 数字版本 | `0.3.3` |
| Debian 软件包版本 | `0.3.3~preview.4`（排序低于最终 `0.3.3`） |
| Apple CFBundleShortVersionString / CFBundleVersion | `0.3.3` / `15` |
| Apple 应用内版本、WOZAI_VERSION 与下载文件名 | `0.3.3-preview.4` |
| Terminal Cargo、CLI `--version`、诊断与下载文件名 | `0.3.3-preview.4` |

所有平台以 [`i18n/config.json`](../../i18n/config.json) 的 `appVersion`、`buildNumber` 为源。修改后运行：

```sh
python3 tools/version.py --write
python3 tools/generate-i18n.py
python3 tools/version.py --check
```

后续预览轮次同时递增 `preview.N` 和 `buildNumber`；同一轮的精确构建用源提交区分。旧开发分支在下次构建前同步版本提交。不同平台沿用自身能力协商和已实现功能，共用版本不代表功能或验收已经完全一致。

历史 tag、附件和旧版发布工具中的固定来源是历史证据，不回写；`publish-native-preview` 工作流只属于已发布 preview.1，不用于发布新轮次。新轮次须单独核验来源、签名、哈希与安装说明。

本轮 preview.4/build15 的[候选包、运行截图、源码与校验值](../screenshots/0.3.3-preview.4/README.md)单独记录；未发布 Release。/ Candidate packages, runtime screenshots, source revisions and hashes are recorded separately; no Release is published.

## 建议交付顺序

1. **发布基础与基本可用性。** 统一上述版本；修复 [#42](https://github.com/GHOST-AKU/wozai/issues/42) 的 AppImage / Ubuntu 22.04 运行时兼容；完成 [#53](https://github.com/GHOST-AKU/wozai/issues/53) 的 Terminal 中英帮助、首启、CLI/TUI 文案；核对 [#43](https://github.com/GHOST-AKU/wozai/issues/43) 的桌面 locale 回退与手动语言选择。仅更新版本不能解决这些问题。
2. **审查已有改进。** 有线/Wi-Fi 发现与多网卡诊断 [#47](https://github.com/GHOST-AKU/wozai/pull/47)；UTF-8 相册导出文件名边界 [#48](https://github.com/GHOST-AKU/wozai/pull/48)；32 KiB 长消息及旧端协商 [#49](https://github.com/GHOST-AKU/wozai/pull/49)；平板按钮、默认/中线双吸附分栏与路由诊断 [#54](https://github.com/GHOST-AKU/wozai/pull/54)。截至本规划创建时均未合并，不能写成正式版已交付。
3. **提高路由判断可信度。** [#23](https://github.com/GHOST-AKU/wozai/issues/23)、[#33](https://github.com/GHOST-AKU/wozai/issues/33)、[#34](https://github.com/GHOST-AKU/wozai/issues/34)：校准 128 KiB 探测窗口与 1 MiB 文件窗口的差异；评估 STA/P2P 并发对 LAN 样本的影响、短样本误差、暂停/迁移成本。验证较差直连切 LAN、断路续传、手动意图与清理。一次探测决策不是实际切换后的反事实收益。
4. **完善 Apple / Terminal 日用流程。** Apple 使用平台原生组件和导航规范，验证 LAN 聊天、文件与目录授权、后台/前台、草稿和多窗口；Terminal 验证完整帮助、45/80/120 列、CJK/Emoji/IME、SSH/tmux、JSON 与授权边界。分别跟进 [#31](https://github.com/GHOST-AKU/wozai/issues/31)、[#38](https://github.com/GHOST-AKU/wozai/issues/38)。iPad 当前不会自动使用 Java 的 P2P 建网或选路逻辑，Apple 传输适配需独立设计，不能只打开一个开关视为完成。
5. **可选增量。** 轻量 Unicode Emoji 选择器 [#52](https://github.com/GHOST-AKU/wozai/issues/52)、官方 Agent Skill [#50](https://github.com/GHOST-AKU/wozai/issues/50) / [PR #51](https://github.com/GHOST-AKU/wozai/pull/51)，各自审查。勾选回执样式 #29 另行排期；不让可选 UI 扩展拖住基础修复。

## 正式发布条件

- 对候选平台核验包内版本、精确源提交、签名状态、安装/升级与数据保留、下载哈希和中英文说明。Apple 签名状态仍按实际产物披露。
- 不把已知无法启动的 AppImage 或尚未完成的中文帮助当作稳定支持；相关平台须修复阻断问题，或明确继续作为实验预览。
- 有线与无线互发现、临时 P2P 建链/真实择路收益/距离断路恢复、大文件与暂停/取消、平板双吸附、Apple 和 Terminal 流程补充真机证据。自动化不代替射频、驱动或存储提供者验收。
- [#32](https://github.com/GHOST-AKU/wozai/issues/32) 补齐端到端有效吞吐和阶段口径；[#9](https://github.com/GHOST-AKU/wozai/issues/9) 继续长期内存和性能验收。没有同环境数据，不承诺更快或具体内存指标。
- 仍使用 NIM4，按实际能力协商；保留旧端长消息兼容、身份/完整性失败不降级、独立客户端身份和数据目录。本地记录未加密及未完成独立安全审计的限制如实保留。
- 多设备并行 #6、LAN→P2P 重新升级 #36、群聊/Mesh/公网中继不自动扩入本轮。没有预设发布日期；实现、审查、构建通过和真机验收分别记录。

## English

This is a **release plan**, not a published release or completed acceptance. [Issue #55](https://github.com/GHOST-AKU/wozai/issues/55) tracks scope and evidence.

Stable **v0.3.2** and the existing Apple/Terminal **v0.3.3-preview.1** retain their original assets. The prior preview.2/build13 and PR #61 retain their source-scoped evidence. The read-receipt development branch advances Android, Windows/Linux GUI, Apple and Terminal metadata together to **0.3.3-preview.3**. `i18n/config.json` owns the full version and build number; `tools/version.py --write` synchronizes Android code14, Apple numeric 0.3.3/build14 and Rust Cargo/lock versions. Regenerate Java resources with `tools/generate-i18n.py`. Windows/jpackage uses numeric 0.3.3, Debian uses `0.3.3~preview.3`, and application displays and package filenames retain the full preview identifier. Increment both preview.N and buildNumber for later rounds. Sync older implementation branches before rebuilding. A shared version does not imply identical capabilities.

Already merged since 0.3.2: recovery isolation and test integration (#37), bounded quality-request retries (#39), current-task recovery snapshots (#40), native SwiftUI Apple clients and streaming files (#35/#44), independent Rust TUI/CLI (#41), and preview packaging/install/README work (#45/#46 and later documentation).

Historical plan at creation (not current merge status): fix release/runtime/localization blockers (#42/#53/#43); review existing Ethernet, filename, long-text and tablet changes (#47–#49/#54, still unmerged); calibrate Direct/LAN measurements and recovery (#23/#33/#34); validate native Apple and Terminal daily workflows (#31/#38). Optional emoji and Agent Skill work (#52/#50/#51) stays separate.

The routing investigation must address the 128 KiB probe versus 1 MiB file window, STA/P2P concurrency bias, short sampling and modeled handover cost. Apple currently uses separate LAN code and does not inherit Java native P2P creation or selection. Real-device throughput and counterfactual improvements cannot be inferred from one probe decision.

Stable gates include usable packages/help, truthful signing and installation instructions, preserved upgrades/data, source/hash provenance, old-peer capability compatibility and physical network/file/UI evidence. Formal performance, end-to-end accounting (#32), long-term memory (#9) and audit limits stay explicit. Platforms with unresolved blockers remain experimental. No automatic release/merge, no promised ship date and no implied completion of native transport parity, multidevice chat, re-upgrade, group chat or Mesh. The historical preview.1 publishing workflow is archival and must not be reused to publish a new round.
