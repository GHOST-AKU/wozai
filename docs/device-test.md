# 构建与双机验收

本清单是后续真实设备验收要求，不表示已完成硬件测试。

当前 0.2.0 尚未编译 APK。用户恢复编译后，在有 JDK 17、Python 3、Android SDK 36 的电脑先运行 `sh tools/test-core.sh`、`sh tools/test-trust.sh`、`sh tools/check-source.sh`，再执行 `./gradlew :app:assembleDebug :app:lintDebug`。确认成功后将同一 APK 安装到两部手机。建议覆盖 Android 8～11、Android 12+ 和 Android 16；两端必须使用 0.2.0，旧版裸帧不兼容。

| 场景 | 操作 | 应观察到 |
| --- | --- | --- |
| 首次启动 | 安装后打开 | 空设备与空历史；不显示虚构会话 |
| 局域网发现 | 双方同 Wi-Fi 开启接收；一方搜索 | 发现对方，地址含有效端口 |
| 局域网直连 | 输入对方显示的 IP:端口 | 发起者点击即同意本次；首次接收方出现记住/仅本次/拒绝 |
| 拒绝聊天 | 任一方拒绝 | 两边释放会话；无法发送 |
| 确认后立即发送 | 确认后马上点发送 | 消息正常到达，不因许可时序断开 |
| 双向中文消息 | 发送中文、换行、颜文字、Emoji | 内容一致，对方存储后显示已送达 |
| 断线与重连 | 断开 Wi-Fi 后重连 | 无响应约 20～25 秒释放；未回执消息未确认；不自动重发 |
| 热点 | 一部开热点，另一部连接 | 发现或直连可用；按厂商路由策略判断 |
| NSD 重复搜索 | 连续搜索、对方停止接收 | 旧搜索回调不会恢复已过期设备 |
| 蓝牙首次授权 | Android 12+ 首次选蓝牙 | 请求附近设备；取消不崩溃；允许后可继续 |
| 旧版蓝牙搜索 | Android 8～11 | 要求定位权限；系统定位关闭时提示检查 |
| 蓝牙发现与配对 | 一方允许被发现，另一方连接 | 系统配对确认；首次来访应用确认；文字正常收发 |
| 蓝牙开关 | 聊天时关闭蓝牙 | 释放会话，停止接收，状态可重启 |
| 中途停止 | 连接尚未完成时停止接收 | 未完成 socket 被关闭，迟到回调不会建立会话 |
| 双方同时发起 | 两边同时点连接 | 可能互相拒绝；只由一方重试发起即可 |
| 通知授权拒绝 | Android 13+ 拒绝通知 | 局域网功能仍可使用；检查系统前台任务显示 |
| 蓝牙启用弹窗返回 | 关闭蓝牙后从应用发起、同意打开 | 自动继续原来的操作；服务重新绑定后也可继续 |
| 弹窗期间旋转 | 授权或打开蓝牙时旋转屏幕 | 恢复待处理操作，成功后只执行一次 |
| 旋转与键盘 | 聊天输入草稿时旋转 | 会话、草稿保留；键盘不遮发送按钮 |
| 后台收件 | 按 Home 后另一方发送 | 持续通知仍存在，回到应用可查看消息 |
| 离线历史恢复 | 停止所有连接，查看某会话，按 Home 再返回 | 当前会话与草稿恢复 |
| 会话切换草稿 | A 写草稿，再查看/连接 B | A 的草稿不会出现在 B 的输入框 |
| 存储失败 | 在专用测试设备制造可控的 SQLite 写入错误 | 不向对方 ACK；发件方草稿不被清空；显示错误并停止连接 |
| 重复消息 ID | 用测试客户端重复发送同一 ID 与内容 | SQLite 只有一条记录，重复消息仍可回执 |
| 改昵称 | 开启接收后修改昵称 | 新连接 HELLO 使用新昵称；发现列表在重启接收后更新 |
| 停止服务 | 通知点击停止所有连接 / 划掉最近任务 | 不再接收或扫描，所有 socket 释放 |
| 本机隐私 | 检查网络与权限 | 无云端接口；设备签名不是实名账号；局域网内容为明文，记录不自动备份 |

## 0.2.0 信任与重连

| 场景 | 操作 | 应观察到 |
| --- | --- | --- |
| 旧版升级 | 从旧版保留数据更新 | 消息保留，信任为空；两端首次重新认可身份 |
| 同意并记住 | 首次连接双方完成就绪 | 信任列表出现设备；重启应用后仍保留 |
| 仅本次 | 发起时关闭记住，或接收方选仅本次 | 未授权一方不新增信任；未来该方收到连接仍需确认 |
| 配对与信任独立 | 只有系统蓝牙配对记录 | 不自动取得应用的聊天信任 |
| 历史 LAN 重连 | 已记住对方换 IP/端口，双方开启接收 | 点击历史连接，重新发现地址且验证密钥，不重复弹应用确认 |
| 历史蓝牙重连 | 已记住且已配对，关闭可发现性 | 用保存地址连接，对方接收开启即可；不要求再次可发现 |
| 对方离线 | 从历史连接 | 超时提示，记录和草稿保留；不显示已连接 |
| 假冒发现 | 测试客户端广播同 UUID、改密钥或指向其他 UUID | 拒绝自动就绪，不替换原公钥 |
| 拒绝/超时 | 首次拒绝或不操作 | 释放会话，不保存新信任 |
| 清空消息 | 对已记住设备清空会话 | 仅删除消息，仍可免确认重连 |
| 取消信任 | 设置/设备信息撤销 | 历史保留；未来来访需重新认可；可选择同时断开 |
| 撤销竞态 | 握手或数据库写入期间撤销 | 迟到 READY/回调不恢复已取消信任 |
| 新旧扫描交错 | 停止搜索后立即重连，延迟旧停止失败回调 | 旧回调不取消新重连；当前停止失败只显示提示 |
| 密钥不可用 | 专用测试设备模拟 Keystore 异常 | 明确无法连接，不生成可绕过认证的新连接 |

## 原生界面与生命周期

| 场景 | 操作 | 应观察到 |
| --- | --- | --- |
| 三页与详情 | 切换聊天/附近/设置、进入消息页 | 左上我在、右上真实连接指示；详情隐藏底部导航 |
| 搜索与空态 | 空历史、匹配/无匹配昵称 | 没有虚构联系人；列表摘要、时间和状态对应本机数据 |
| 深色与大字体 | 系统深浅色、150% 字号、360dp/412dp 宽度 | 字体清晰、操作不裁切、触控范围足够 |
| 键盘/系统栏 | 手势和三键导航，展开键盘、旋转、多窗口 | 输入栏可见、发送间距足够、气泡不超宽 |
| 重开同会话 | 阅读旧消息、返回列表、重新打开 | 原阅读位置保留；同会话重连也不跳底 |
| 阅读期间收件 | 向当前阅读历史的会话发消息 | 不强制跳底，显示新消息入口 |
| 切换连接 | 正在与 A 聊天时选择 B | 明确结束当前会话后连接，不静默替换 |
| 取消/授权旋转 | 扫描、连接、蓝牙许可弹窗期间旋转 | 待处理动作只执行一次；取消后迟到 socket 不建立会话 |
| 无扫描权限重连 | Android 12+ 仅有 CONNECT，已有可信蓝牙地址 | 已知地址连接不因取消扫描的权限异常失败 |
| 读屏/动画 | TalkBack；系统关闭动画 | 可读出操作与状态；关闭动画后无强制切页动画 |

蓝牙硬件测试需要真实手机；安卓模拟器主要用于界面、数据库与局域网调试。前台服务不能保证在厂商省电策略或系统强杀后存活。
