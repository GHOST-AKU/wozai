# 构建与双机验收

本清单是后续真实设备验收要求，不表示已完成硬件测试。

先在有 JDK 17、Android SDK 36 的电脑执行 `./gradlew :app:assembleDebug :app:lintDebug`，确认两项均成功，将同一 APK 安装到两部手机。建议至少覆盖一部 Android 12+ 设备和一部 Android 8～11 设备。

| 场景 | 操作 | 应观察到 |
| --- | --- | --- |
| 首次启动 | 安装后打开 | 空设备与空历史；不显示虚构会话 |
| 局域网发现 | 双方同 Wi-Fi 开启接收；一方搜索 | 发现对方，地址含有效端口 |
| 局域网直连 | 输入对方显示的 IP:端口 | 建立链路并弹出双方确认 |
| 拒绝聊天 | 任一方拒绝 | 两边释放会话；无法发送 |
| 确认后立即发送 | 确认后马上点发送 | 消息正常到达，不因许可时序断开 |
| 双向中文消息 | 发送中文、换行、颜文字、Emoji | 内容一致，对方存储后显示已送达 |
| 断线与重连 | 断开 Wi-Fi 后重连 | 无响应约 20～25 秒释放；未回执消息未确认；不自动重发 |
| 热点 | 一部开热点，另一部连接 | 发现或直连可用；按厂商路由策略判断 |
| NSD 重复搜索 | 连续搜索、对方停止接收 | 旧搜索回调不会恢复已过期设备 |
| 蓝牙首次授权 | Android 12+ 首次选蓝牙 | 请求附近设备；取消不崩溃；允许后可继续 |
| 旧版蓝牙搜索 | Android 8～11 | 要求定位权限；系统定位关闭时提示检查 |
| 蓝牙发现与配对 | 一方允许被发现，另一方连接 | 系统配对确认；双方聊天确认；文字正常收发 |
| 蓝牙开关 | 聊天时关闭蓝牙 | 释放会话，停止接收，状态可重启 |
| 中途停止 | 连接尚未完成时停止接收 | 未完成 socket 被关闭，迟到回调不会建立会话 |
| 双方同时发起 | 两边同时点连接 | 可能互相拒绝；只由一方重试发起即可 |
| 通知授权拒绝 | Android 13+ 拒绝通知 | 局域网功能仍可使用；检查系统前台任务显示 |
| 蓝牙启用弹窗返回 | 关闭蓝牙后从应用发起、同意打开 | 自动继续原来的操作；服务重新绑定后也可继续 |
| 弹窗期间旋转 | 授权或打开蓝牙时旋转屏幕 | 恢复待处理操作，成功后只执行一次 |
| 旋转与键盘 | 聊天输入草稿时旋转 | 会话、草稿保留；键盘不遮发送按钮 |
| 后台收件 | 按 Home 后另一方发送 | 持续通知仍存在，回到应用可查看消息 |
| 离线历史恢复 | 停止所有连接，查看某会话，按 Home 再返回 | 当前会话与草稿恢复 |
| 会话切换草稿 | A 写草稿，再查看/连接 B | A 的草稿不会出现在 B 的输入框 |
| 存储失败 | 在专用测试设备制造可控的 SQLite 写入错误 | 不向对方 ACK；发件方草稿不被清空；显示错误并停止连接 |
| 重复消息 ID | 用测试客户端重复发送同一 ID 与内容 | SQLite 只有一条记录，重复消息仍可回执 |
| 改昵称 | 开启接收后修改昵称 | 新连接 HELLO 使用新昵称；发现列表在重启接收后更新 |
| 停止服务 | 通知点击停止所有连接 / 划掉最近任务 | 不再接收或扫描，所有 socket 释放 |
| 本机隐私 | 检查网络与权限 | 无云端接口、无身份认证；局域网为明文，记录不自动备份 |

蓝牙硬件测试需要真实手机；安卓模拟器主要用于界面、数据库与局域网调试。前台服务不能保证在厂商省电策略或系统强杀后存活。
