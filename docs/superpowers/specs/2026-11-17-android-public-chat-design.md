# Android Next 公共聊天体验

本轮根据所有者的实施请求，基于 main `4851754`，仅调整 Android Next 公共聊天体验。主 agent 独立完成，不合并、不发布，不纳入 #101/#103/#108。

## 方案与范围

保留现有“会话 / 附近 / 设置”导航及私聊入口；精简附近页的公共聊天。相比重做导航或更换 Mesh 内核，这种方式直接改善日常聊天并保留已有实机通过路径。沿用 Kotlin/Compose、MeshService 与 Rust Core，不改公开线协议、NIM4、身份或数据库。

主页面只显示公共聊天标题、连接/接收状态、消息、输入与开启/停止；模式、中继、电脑可发现和诊断放入选项。首次手动开启显示可滚动的公开性、接收、后台停止入口与历史告知，记录告知版本，后续开启继续经过权限/无线检查，不自动运行。公共运行即收发，无需逐条接收或认可；中继每次运行默认关闭。

传输模式来自 Android 版本、进程 ABI 和系统硬件 feature；仅允许选择本机支持的模式。不把硬件支持、无线已开启、权限已授予及真正连接混为一谈。蓝牙继续使用既有 CoC + RFCOMM；Wi-Fi Aware 为独立实验路径。不笼统否认已有 Android/Windows 蓝牙与中继实机反馈。

状态区分关闭、启动、寻找附近设备、已连接直接邻居。消息排队不等于送达，交给邻居不等于其他人全部收到/已读；签名验证不等于身份信任。无邻居可暂存待发，由原内核过期处理。

临时历史沿用现有最多 200 条、仅进程内保留；停止/重开 Mesh、切页/旋转不主动清除，进程退出/被系统结束或覆盖升级重启后消失，超过上限移除最早消息。历史展示不代表仍会转发。私聊历史、身份、信任、设置与 Mesh profile 不迁移、不清理。

## 验证与交付

新增硬件筛选、首次告知/取消、控制项收纳、连接与消息状态、临时历史边界回归。复用现有真实内核与无线适配回归，不要求所有者重复已成功的射频测试。版本升为 0.4.0-preview.8/build23，从 i18n/config.json 生成。签名只使用已有 CI Secrets 和既有签名步骤；最终 APK 必须通过持久证书、包名、版本、非 debug、源码及 Mesh 原生输入校验。新 UI 自动化不能冒充真机视觉/无线验收。
