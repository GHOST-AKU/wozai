# 我在next · WinUI 3 桌面实验

目标：为现有 Windows 客户端建立功能完整的 WinUI 3 原生实验界面，并提供真实 Windows 运行截图。沿用本次对话对独立安装、精致干净原生风格、通信内核不变的要求。

方案：C# / WinUI 3 负责原生界面和系统选择器，通过私有标准输入输出管道调用复用的 Java DesktopClient。相比重写 NIM4，这保留现有协议、加密、信任、传输、回执和存储实现；相比嵌入旧 Swing 窗口，这使窗口、导航、列表、菜单和对话框成为 WinUI 控件。Java 运行时随便携包携带，数据存放独立目录，不导入原客户端身份。

功能对齐：LAN 和 Windows 经典蓝牙的接收/发现/连接，首次认可、记住/撤销信任，文字、历史、搜索、草稿、真实回执、已读策略，照片/多文件、预览、暂停/续传/拒绝/重发/队列、打开/另存、路径与诊断，安全码/二维码核验，头像，语言、主题、字号、配额及隐私说明。能力与当前 Windows 内核相同，不宣称新增桌面 Wi-Fi Direct、语音或多会话并行。

架构契约见 `windows-next/PROTOCOL.md`。列表和对话框使用可滚动布局；文件选择和核验带会话代次，异步发送只清除匹配的原草稿。启动不暴露监听；窗口关闭清理子进程；桥接异常有可理解提示。已读依据实际前台正文可见性，不依据选中会话。

验证：适配层端到端调用真实原内核，覆盖未知身份认可、文本与文件互通/保存、草稿持久化和安全边界；Windows runner 编译、打包并实际启动 WinUI 3，生成会话/附近/设置/深色等窗口截图。测试数据与物理无线验收明确区分。截图不由绘图工具或 HTML 模拟。真实蓝牙和跨设备无线/大文件性能仍需设备验收，不以 CI 截图替代。
