# 我在next：Android 实验客户端

用户要求以 Kotlin / Jetpack Compose 重构安卓界面，方向为精致、干净、原生，通信内核不变；用户已选择独立安装的实验客户端。

## 方案与边界

采用独立 `:app-next` 模块和 `dev.ghost.nearbyim.next` applicationId。直接复用原 `app` 的 Java 源码及资源，仅替换主 Activity，避免分叉协议、数据库、身份、通信服务与文件传输逻辑。原 `:app` 继续保留。相较直接替换原客户端，这允许并行体验；相较复制通信代码，这保证后续内核修复同步生效。

独立安装意味着独立 Android 沙箱、密钥、信任、记录和草稿，不自动导入旧端数据。应用名称为「我在next」。版本与 buildNumber 仍读取 `i18n/config.json`，不改发布版本。

## 体验

Material 3 原生导航、系统字体、低饱和绿色、留白和克制的圆角，支持动态色彩、深浅色、边到边与系统字号。会话、附近、设置三入口；宽屏采用会话与聊天分栏。附近提供 LAN / 蓝牙、接收、搜索、地址直连和首次设备认可。聊天提供文字、系统文件/照片选择器、附件状态和传输操作、真实送达与已读状态。身份核验以现有安全码为依据，不以昵称或发现信息认定身份。

所有通信通过原 ChatService / ChatController。默认不启动接收或发现。发送只在保存完成后清除匹配草稿；文件选择结果绑定原设备和会话。已读仅针对前台、解锁、有焦点且实际可见的文字消息。

## 验证与交付

对异步草稿、UTF-8 限制和文件选择会话边界做 JVM 回归。执行 app-next 的测试、构建和 lint；核对原通信源码未修改。若无模拟器/真机，明确记录运行与无线互通尚未验收。所有安装交付 APK 必须通过仓库持久签名校验，内部 debug 构建不作为可安装交付。

这是新 UI 的实验实现。头像裁剪、照片查看、附件顺序预览及附件导出继续复用既有原生 Activity / 控制器；二维码相机/图片核验入口等未迁移的体验在 `docs/android-next.md` 明确，不能声称完成全量真机验收。
