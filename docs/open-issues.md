# 未解决问题与待验收事项

更新：2026-10-03。当前发布版本为 [0.3.1 Preview 1](https://github.com/GHOST-AKU/wozai/releases/tag/v0.3.1-preview.1)，三端应用版本均为 0.3.1，发布源码提交为 `26cf485`。

本文记录当前讨论中尚未解决的事项。用户反馈、已确认的实现限制与待完成的设备验收分别标明；构建或自动测试通过不代表以下事项已解决。后续取得复现结果或交付修复后，在原条目中更新状态和证据。

## U001 · Windows 有线网络下搜索不到局域网设备

**状态：用户反馈，待定位。优先处理。**

- 已知现象：用户家中的 Windows 电脑连接有线网络，反馈局域网「搜索不到」。目前不能据此断言有线网络完全无法通信。
- 尚未确认：搜索发生在哪一端、对端平台、双方是否在同一可达局域网、手动输入有线网卡的完整 `IP:端口` 能否连接，以及电脑是否存在 VPN／虚拟网卡。
- 已检查的实现：桌面 TCP 接收没有仅允许 Wi-Fi 的限制；自动发现使用 mDNS。当前桌面发现只为枚举到的前四个符合条件的 IPv4 地址建立 JmDNS 实例，多网卡时可能遗漏实际有线地址。这是排查线索，尚未证明是本次故障原因。
- 下一步：先记录双端版本、网络连接方式、地址与搜索方向；验证手动直连，再检查 Windows 专用网络防火墙规则、UDP 5353 组播、路由器有线／无线或访客网络隔离，以及客户端网卡选择与发现失败信息。排查时不要要求关闭整个防火墙。
- 完成标准：在同一可达家庭局域网中，Windows 有线电脑与 Wi-Fi 对端能够双向发现、连接、文字互传及保存回执；同时覆盖多网卡／虚拟网卡场景，并记录复现原因、修复或配置依据。若网络本身阻止发现，应用应提供可理解的提示与直连入口。

**当前结论：尚未复现、尚未定位、尚未修复；手动直连结果待反馈。**

## U002 · 同时只能维持一个聊天连接

**状态：已确认的功能限制，尚未扩展。**

- Android、Windows、Linux 当前均只有一个活动聊天会话。局域网和蓝牙共用这个名额；活动会话或连接尝试期间，其他连接被拒绝。
- 与 B 聊天时联系 C，需要先断开 B，再连接 C；历史记录、草稿和已记住的设备信任保留。切换历史记录页面不会建立第二条连接。
- 后续方向：先设计同时与多个设备分别私聊的会话管理，再独立设计群聊。具体连接数、各平台蓝牙限制和资源上限尚未确定，未承诺实现时间。
- 完成标准：A 能同时维持与 B、C 的独立私聊，切换聊天页面不必断开连接；消息、回执、信任、草稿和撤销操作按设备正确路由；一条连接失败不会误关闭其他连接，退出能释放全部资源。

**当前结论：多人同时私聊和群聊均未实现。**

## U003 · Windows／Linux 蓝牙跨平台真机验收

**状态：实现与自动测试已交付，真实射频验收待完成。**

- Windows 原生蓝牙桥接与 Linux BlueZ RFCOMM 已包含在预览包中。Linux 的 D-Bus 契约、JNI 文件描述符、NIM2 聊天、存储和回执链路测试已通过。
- 本轮开发环境没有真实蓝牙适配器，不能用这些测试证明系统配对或跨设备无线互传。此前用户报告过 Android 0.2.0 双机互通，不能替代当前桌面预览版的验收。
- 下一步：使用真实适配器与测试设备，分别验证 Android ↔ Windows、Android ↔ Linux、Windows ↔ Linux 的双向发现、配对、首次认可、文字互传、保存回执、可信重连和撤销；覆盖配对拒绝／取消、适配器禁用、服务重启和离开范围。
- 完成标准：记录设备、操作系统、软件版本、适配器与双向结果；失败项定位并修复后重验。

详细清单见 [Linux 验证记录](linux-verification.md#真实设备验收) 和 [设备验收清单](device-test.md#通信与权限)。

## U004 · Android 预览包签名与保留数据升级

**状态：已知发布限制，长期签名方案待确定。**

- 本次 Android 预览 APK 使用 CI 临时调试证书。证书不匹配时不能覆盖已有 APK；发布版本号相同并不代表签名兼容。
- 尚未建立后续预览／正式发布可持续复用的签名与密钥管理流程。新密钥也不能让已有其他证书签名的安装包直接升级。
- 下一步：确定发布签名的持有与安全管理方式，核对用户已安装包的证书，并使用同一证书验证保留数据升级；对于不能取得原密钥的安装，另行确定数据迁移方案。
- 完成标准：后续发布可重复使用已确定的签名；同证书升级保留消息、设备身份、信任与草稿；不兼容签名的处理方式明确，不能以卸载有聊天记录的旧应用作为解决办法。

当前证书随 Release 的 `ANDROID-SIGNATURE.txt` 提供。升级说明见 [设备验收清单](device-test.md)。
