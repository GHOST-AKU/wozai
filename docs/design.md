# 我在 Android 设计

目标：两部安卓设备无需账号和远程服务器，通过同一局域网或经典蓝牙进行一对一文字聊天。

用户明确要求：安卓 IM，支持蓝牙或局域网。本项目实现两者。
默认范围：Android 8.0+、中文原生界面、文字与颜文字、本地聊天记录、连接确认、送达回执。群聊、文件、跨互联网通信不包含在此版本。

架构：Activity 展示状态并申请权限；前台 ChatService 持有 ChatController；LanTransport 使用 TCP 与 NSD；BluetoothTransport 使用安全 RFCOMM。两种传输均提供 StreamConnection，交给同一个 FramedSession。

协议：NIM2 签名封装包裹既有帧。长期 P-256 密钥、双方随机挑战与方向绑定证明当前设备持有私钥；就绪后的每条帧附序列与签名，拒绝篡改、跨会话重放与旧版裸帧。HELLO 交换本地 UUID 与昵称；双方 READY 后允许 TEXT 和 ACK。单条文字不超过 8192 UTF-8 字节，昵称不超过 32 Unicode 码点。发送状态为待确认、已送达、未确认；断线不自动重发。详见 `protocol-v2.md`。

数据：SQLite 保存会话、消息和独立的设备信任；私钥留在 Android Keystore。接收消息保存成功才 ACK，按对方 UUID 与消息 UUID 去重。点击发起即同意本次聊天；来访首次选择记住或仅本次。双方就绪且认可记住后保存公钥，未来来访验证匹配公钥可自动就绪。撤销独立于清空历史，迟到握手不能恢复已撤销授权。身份不是经过认证的账号。局域网内容为明文，签名只提供身份连续性和完整性；蓝牙使用系统认证与链路加密，不声称端到端加密。应用数据不自动备份。

界面：聊天 / 附近 / 设置三页，首页左上「我在」，右上实际聊天连接指示。聊天列表使用真实本机摘要与首字头像，详情隐藏底部导航。历史可直接重连；LAN 重新发现当前地址，蓝牙使用已保存地址，最终均验证公钥。保留按会话区分的草稿、消息保存成功后清空输入、读历史时不强制跳底。浅色为设计基准，深色跟随系统；短暂切页动画遵循系统动画开关。

运行：连接工作由 connectedDevice 前台服务维持，显示持续通知；不申请电池优化豁免。关闭连接或移出最近任务时释放所有资源，不承诺系统强杀后仍在线。

验证：JDK 无第三方依赖的核心测试覆盖真实 TCP 双向消息、确认前限制、断线、重复 ID、非法帧和地址验证；安卓构建与硬件测试需要 Android SDK 和两部真实手机。
